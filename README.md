# Smashipelago

Bizhawk 2.10 and a legally obtained Usa copy of the smash bros 64 rom are required

Setup Instructions

1. install the latest apworld from the releases page
2. Generate a yaml, either through the options creator in the ap launcher or generate a template yaml
3. generate multiworld
4. collect the .apsmash64 file from the host website or the output the host generates
5. open the .apsmash64 through the ap launcher
6 have fun
